
We decided to do a single page application with 4 stages(List, Start, Questions, Leaderbaord). 
The application was built using principles of Object-Oriented Programming.
We also added fade-in fade-out animations, aswell as correct, wrong  animations. We also made the app proggresive, added google analytics, share to twitter, we also added a qr code scanner, our app also get the location, you can also start from the begging if you want. 
The application is fully functional we utilized all of the api functionality, and everything is saved by cookie files.
We also done heuristic testing, user aceptance testing and unit testing.
